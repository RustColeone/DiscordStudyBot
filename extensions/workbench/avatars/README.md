# Classmates' pictures

The workbench page shows each classmate with a picture named after her (`luna.png`, `claude.png`,
`deepseek.png`, `gemini.png`, `grok.png`, and `you.png` for you). It looks here first, then in the web UI's
[`plugins/webui/avatars`](../../../plugins/webui/avatars), so the same pictures appear in both without copying
them. PNG, JPEG, WebP or GIF, square works best. Without one, a classmate gets a coloured circle with her initial.
