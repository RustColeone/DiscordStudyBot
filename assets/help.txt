=== AGENT ===
# Collaborative Agent Team

Mention the bot with a request, or use:
$agent <request>           Ask the team to answer or perform an action
$agent tools               List actions available to the agent
$agent confirm             Approve concrete pending writes
$agent cancel              Cancel pending room work
$agent --trace <request>   Show observable room progress
$agent 报数                Four-person team check-in (also: roll call)

The room owns conversation and work through one shared loop. Characters speak briefly, use tools,
or assign teammates focused steps. Direct group address such as “你们” or “you all” starts all four
independently; replies appear as they finish. Naming characters starts those voices; otherwise the
initial speaker rotates. Jobs wait only for their specific prerequisites. Work updates describe
actual steps and results. All characters receive the configured local time for relative expressions.
Writes need central approval, and unfinished work resumes after an answer or confirmation.

=== CHAT ===
# Unified AI Chat System

Modes:
$chat --mode agent      Collaborative agent team (default)
$chat --mode roleplay   Provider/persona mode

In agent mode, characters share dialogue, a work board, and verified tool results. Each keeps her
own selective private diary. Casual conversation and tool work use the same loop, with no separate
router, planner, or task owner. Independent jobs run together; failed prerequisites block dependent
work. Character messages appear before tools run. Work notes remain visible without --trace.
Short inline LaTeX becomes Unicode; display equations are rendered as embedded images.
Grounded replies use actual retrieved source links. Ask explicitly for a detailed deliverable when needed.
Default team models: GPT-6 Luna, Gemini 3.8 Flash, Claude Haiku 5.5, DeepSeek V4.1 Flash.
Team models, personalities, and effort are
server-admin configured. Search falls back to keyless retrieval if Google grounding is
unavailable. Google Maps grounding is currently English-only.

Basic Usage:
$chat                    Show current status
$chat -s <message>       Send message (or --send)

Configuration:
$chat -l <name>          Set role-play LLM: chatgpt, gemini, deepseek
$chat -m <name>          Set role-play model
$chat --effort <level>   Set role-play effort: low, medium, high, max
$chat --models           List all available LLMs and models
$chat -st                Show configuration (or --status)

Prompts:
$chat -p list            List preset prompts (or --prompt)
$chat -p show            Show current prompt
$chat -p <0-3>           Set preset by index
$chat -p set <text>      Set custom prompt

Provider, model, effort, and prompt changes are available to everyone in role-play mode.
Agent team configuration is restricted to the server administrator.

History & Modes:
$chat -c                 Clear chat history (or --clear)
$chat --listen on        Enable listen mode (auto-respond to all messages)
$chat --listen off       Disable listen mode
$chat --trace -s <msg>   Keep a separate live process-notes message for this request

Safe planning and tool milestones are appended as they happen. A generated high-level recap follows.
Process notes are not private model chain-of-thought.

The agent answers from its own knowledge by default. It searches only for current, explicitly
researched, or genuinely obscure facts, and reads links only when their contents matter.

Older chat turns are automatically compressed into a durable summary near the model's context limit.
$chat -c removes both recent turns and compressed context for the active LLM.

Command Chaining Examples:
$chat -l gemini -m gemini-1.5-pro -s Hello
$chat --mode roleplay -c -l deepseek -p 2 -s Fresh start with custom prompt
$chat -l chatgpt -m gpt-4 -p 0 -s Test

Available LLMs:
• chatgpt: gpt-3.5-turbo, gpt-4, gpt-4-turbo
• gemini: gemini-3.8-flash, gemini-3.7-flash, gemini-3.6-flash
• deepseek: deepseek-flash

Preset Prompts:
• 0: CETACEA_LOLI for DeepSeek; Short Assistant for other providers (default)
• 1: Blank
• 2: Misaka Minoto
• 3: Saber

=== MEMORY ===
# Character Diaries

$memory                           Show diary commands
$memory DeepSeek                  Read DeepSeek's notes about you in this room
$memory DeepSeek 2                Read an older page of notes
$memory Luna                      Read Luna's notes
$memory Gemini                    Read Gemini's notes
$memory Claude                    Read Claude's notes
$memory forget <character> <id>    Remove one note shown in a diary
$memory clear <character>          Remove that character's notes about you in this room

Each character decides whether a personal fact, preference, goal, or meaningful moment is worth
keeping. Notes are short paraphrases in her own voice. Routine conversation is usually not saved
as a diary entry. Corrections can revise an existing fact instead of adding contradictory notes.
The characters have separate diaries, scoped to the current user and room. Diary updates are
part of normal response generation, without an extra AI call or a public update announcement.
$chat --clear resets chat history; use $memory clear to remove diary notes.

=== MUSIC ===
# Music Player Commands

Initialize:
$music -i                Connect to your voice channel (or --init)

Playback:
$music -p                Play/resume (or --play)
$music --pause           Pause playback
$music -s                Stop and disconnect (or --stop)

Navigation:
$music -n                Next song (or --next)
$music --prev            Previous song (or --previous)
$music --name            Show current song name

YouTube Playback:
$music -y <url>                Play YouTube video (or --youtube)
$music -y "url1" "url2"        Add multiple, play first
$music -y --queue "url1" "url2" Add multiple to queue

Playlist Behavior:
• YouTube URLs from -y command are added to runtime playlist only
• Default: inserts after current song and skips to first one
• With --queue: adds all to queue without interrupting current song
• Multiple URLs are inserted in order after current position
• Original musicList.txt is never modified by -y command
• Add YouTube URLs directly to musicList.txt for permanent playlist
• Mix local files and YouTube URLs in the same playlist
• Navigate between local/YouTube tracks with --next/--prev

Legacy Format:
Old commands still work: $music initialize, $music play, etc.

=== DRAW ===
# Image Generation

$draw <description>                  Generate with the configured default
$draw -p <provider> <description>    Choose gemini or openai
$draw -p <provider> -m <model> <description>
$draw --models                       Query available models from both providers
$draw --models -p <provider>         Query one provider
$draw --status                       Show configured defaults

Describe the subject, style, composition, lighting, colors, and other constraints in ordinary
language. Attach or reply to an image to use it as a visual reference.

Examples:
$draw a moonlit library in anime style
$draw -p openai -m gpt-image-2.5-flare a square watercolor reading icon
$draw -p gemini -m gemini-3.1-flash-image redesign the attached poster

The default provider is Gemini with `gemini-2.5-flash-image` (Nano Banana). OpenAI supports
GPT Image 2.5 Sunburst and Flare. `$draw --models` merges each provider's live catalog with the
current supported model set, so configured models remain visible if a catalog lookup is unavailable.

Natural requests also work through collaborative chat:
$chat -s "draw a moonlit library in anime style"

Collaborative image requests remain owned by Gemini so Luna can plan and audit the task without
changing the room's teammate responsibilities. Direct `$draw` provider choices do not alter chat.

=== SEARCH ===
# Search & Computation

Wolfram Alpha:
$wolfram -q <query>      Query Wolfram Alpha (or --query)
$wolfram <text>          Legacy format (no flag)

Web Research:
$google -s <query>       Research and synthesize an answer with sources (or --search, -q)
$google <text>           Legacy format (no flag)

Linked Pages:
Use $chat -s, $agent, a bot mention, or listen mode with a public HTTP(S) page.
A bare link is summarized automatically.
Add a question with the link to ask about its contents. HTML, plain text, JSON, and text-bearing PDFs are supported.
The agent can follow source and section links discovered during research.
Private-network URLs, oversized pages, credentialed URLs, and unsupported binaries are rejected.
Sources remain clickable, but Discord preview cards are suppressed in sourced answers.

Examples:
$wolfram -q integrate x^2
$google -s Python documentation

=== BRIDGE ===
# External App Bridge System

$bridge --help and $help bridge render the live parser command catalogue.
Named bridge selection is remembered per Discord channel.
The maintained example demonstrates the lifecycle; the Linux WeChat bridge provides owner-only
QR login, chat reading, explicit sends, bound forwarding and independent notification subscriptions.
Automated replies require whitelist membership, an enabled assistant and explicit group mentions.
Configure names and group aliases live; no group names are built into the implementation.
Current-chat text/file delivery is preauthorized by its whitelist; privileged writes still need owner approval.
See docs/WECHAT_BRIDGE.md for setup, architecture and desktop-client limitations.

=== CLIP ===
# Video Clip Extraction

Extract clips from YouTube, Bilibili, and 1000+ other sites

Basic Usage:
$clip -u "url" -s <start> -e <end>    Preview clip
$clip -u "url" -s 5 -e 15              Start at 5s, end at 15s
$clip -u "url" -s 1:05 -e 1:15         Time format: MM:SS
$clip -u "url" -s 5                    Start at 5s to end of video
$clip -u "url" -e 30                   From beginning to 30s
$clip -u "url"                         Entire video (if fits limit)

Format Options:
$clip -u "url" -s 0 -e 10 --format gif    Convert to GIF
$clip -u "url" -s 0 -e 10 --format mp3    Extract audio only
$clip -u "url" -s 0 -e 10 --format mp4    Video (default)

Quality Control:
$clip --resolution 720p       Set resolution (1080p/720p/480p/360p)
$clip --fps 30                Set frame rate
$clip --bitrate 1500k         Set video bitrate

Multiple Clips:
$clip -u "url1" -s 5 -e 15 -u "url2" -s 20 -e 30

Workflow:
1. Preview: Shows size estimate and quality options
2. Adjust: Modify settings if over Discord limit
3. Confirm: Process and upload

Commands:
$clip --confirm               Process pending clips
$clip --confirm --skip 2      Skip clip 2
$clip --clip 2 --resolution 720p   Adjust clip 2
$clip --keep-file            Keep generated clip file after sending
$clip --delete-file          Delete generated clip file after sending
$clip --cancel                Cancel all pending
$clip --force                 Skip preview, process immediately

Cleanup helper:
python cleanup_old_clip_files.py --max-age-minutes 60

Size Limits:
Auto-detected based on server boost:
• No boost: 10MB
• Level 2: 50MB
• Level 3: 100MB

Supported Sites:
YouTube, Bilibili, Vimeo, Twitter/X, TikTok, Twitch, SoundCloud, and 1000+ more
