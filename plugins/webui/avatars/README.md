# Classmates' pictures

Each student's picture is her own, in the students module (`extensions/students/<name>/avatar.png`), and every page
shows it. Drop a picture here to use another one on this page, named after her (lowercase, letters and digits only):

| File | Shown for |
| --- | --- |
| `gpt.png` | GPT |
| `gemini.png` | Gemini |
| `claude.png` | Claude |
| `deepseek.png` | DeepSeek |
| `grok.png` | Grok |
| `you.png` | You (your own bubbles) |
| `bot.png` | Messages without a speaker (notices, command results) |

PNG, JPEG, WebP or GIF; square works best (they are shown as circles, 40–96 px). Anyone without a
picture gets a soft coloured circle with their initial. Reload the page after adding one.
