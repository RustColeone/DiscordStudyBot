# Cafe rooms

The cafe (`/cafe`) offers three drawn rooms (Sunny café, Quiet library, Rooftop). Every picture dropped here is a room
as well: PNG, JPEG, WebP or GIF, its file name in lowercase letters, digits, `-` and `_` (`garden-terrace.png` becomes
"Garden terrace"). Wide pictures work best (16:9); the students walk on the lower third. Reload the cafe to see a new
one. Which room is shown is remembered by each browser.
